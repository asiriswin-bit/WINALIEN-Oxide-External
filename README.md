# WIN ALIEN — Oxide External

Лоадер для ПК и Android external под Oxide 1.13.11924 x86_64 в MSI App Player/BlueStacks.

## Изменения 0.2.10

- Camera Aim: Head / Neck / Chest / Pelvis / Nearest to crosshair, FOV, Smooth, дальность и максимальная скорость поворота.
- Активация While ADS или Always; по умолчанию Aim выключен. Открытое меню приостанавливает наведение.
- Приоритет по прицелу или расстоянию, удержание цели, фильтры соклановцев и спящих. Мёртвые игроки исключены.
- Круг FOV учитывает zoom, есть настройка цвета и маркер цели. Все параметры сохраняются в CFG.
- Кости для Aim читаются независимо от ESP/Skeleton. Недоступная кость не заменяется выдуманной точкой над игроком.
- Сохранены визуалы, именованные CFG и параметры оружия из предыдущего релиза.

## Обновление

1. Останови external старым лоадером и закрой его.
2. Замени **OxideLoader.exe**. Кнопка «Скачать файлы» не обновляет сам EXE.
3. Нажми «Скачать файлы», дождись `oxide-11924-v0.2.10`, затем «Старт external».
4. Для Aim: Aimbot → Enable Camera Aim → выбери кость, FOV и Smooth → закрой меню. While ADS требует игрового прицеливания.
5. Для деревьев включи Trees; для печек/ящиков Deployables, транспорта Vehicles, бочек/знаков Scrap.

Протокол **5**: EXE и бинарник обновляются вместе. Старые настройки сохраняются. World поддерживает текст/иконки/оба, дистанцию, цвет, размер, разрежение и лимит объектов. В Config именованные пресеты хранятся отдельно от автоматического сохранения текущих настроек. Экспорт: `/data/local/tmp/configs/exports/`; импорт: `.cfg` из `/data/local/tmp/configs/imports/`. Облачные share-коды не подключены.

Крестик/Escape скрывают меню; watermark и Insert открывают его. F6 переключает ESP. Меню и ESP работают внутри эмулятора через SurfaceControl + EGL/OpenGL ES 3; Windows ImGui/DX11 используется лоадером. Для MSI используется встроенный `/system/xbin/bstk/su`; активационный ключ не нужен.

## Проверки и ограничения

Все 14 наборов CTest прошли: чтение сцены и костей, геометрия FOV, фильтры целей, сглаживание, ограничение скорости, блокировки записи, CFG, загрузка и меню. Smoke при 100% и 150% прошёл, включая выбор кости. Скриншоты выше синтетические.

**Подключённого эмулятора нет: работа Camera Aim 0.2.10 в игре пока не подтверждена.** Aim поддерживает игроков x86_64 Oxide 11924; NPC и проверка препятствий не подключены. Tracking подтверждает успешный вызов записи углов, но не попадание. Silent Aim, AutoFire, AutoFarm, Auto Kill и свободная камера не реализованы. Обход античита не заявляется.
