# WIN ALIEN — Oxide External

Windows loader и overlay для Oxide 1.13.11924 ARM64 в Android-эмуляторе.

**[Скачать OxideLoader.exe](https://github.com/asiriswin-bit/WINALIEN-Oxide-External/releases/latest/download/OxideLoader.exe)** · [Релизы](https://github.com/asiriswin-bit/WINALIEN-Oxide-External/releases/latest)

## Запуск

1. Сохрани `OxideLoader.exe` в отдельную папку и запусти его.
2. Нажми «Скачать файлы». Loader скачает ADB, необходимые DLL и сборщики из GitHub Release, проверит размеры и SHA-256. При нажатии «Старт external» эта проверка выполняется автоматически.
3. Запусти 64-битный Android-эмулятор с Oxide 11924 ARM64; включи ADB и root внутри эмулятора.
4. Укажи локальный порт ADB, нажми «Проверить подключение», затем «Открыть Oxide».
5. После входа в игру нажми «Старт external». Во вкладке «Окно и профиль» выбери окно эмулятора, во вкладке «ESP и визуалы» настрой отображение.

Ключ активации и аккаунт GitHub не нужны. Файлы сохраняются рядом с EXE в `runtime-cache`. При недоступности GitHub loader может использовать ранее скачанный комплект после повторной проверки. Новую версию самого EXE нужно скачать из релиза вручную.

## Состояние сборки

Версия 0.2.0: сборка Windows и двух сборщиков, автоматические проверки и рендер интерфейса пройдены. Работа на живой игре пока не проверена. Обход античита не реализован.

Возможности: категории ESP, имена, дистанции, HP, рамки и линии, radar, прицел, таблица объектов, привязка overlay к окну и сохранение настроек. Android-интерфейс, Aim и AutoFarm в эту сборку не входят.

Этот репозиторий содержит описание и готовые файлы в Releases. Исходники распространяются отдельно.

## Компоненты

Loader использует Dear ImGui; лицензия находится в [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt). Файлы Android Platform Tools сопровождаются `NOTICE.txt` в релизе и скачанном комплекте.
