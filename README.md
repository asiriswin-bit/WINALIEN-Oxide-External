## Версия 0.2.16

Возврат к external: лоадер больше не скачивает и не отправляет библиотеку или injector, payload не загружает внутренний модуль.

**Render visibility** читает Unity `Renderer.isVisible` тела и головы игрока/NPC. Это приблизительный сигнал рендеринга: он может учитывать другие камеры и тени, поэтому не доказывает отсутствие стены или возможность попадания. Цвет настраивается, неизвестные данные не подсвечиваются. В Aim есть отдельный фильтр **Require rendered model**. Обе опции выключены по умолчанию.

**Надёжного external Silent пока нет.** Режим `Silent (unavailable)` не делает записей Aim и не загружает модуль. Для обычного наведения используй **Camera**. Прежний внешний цикл записи направления удалён: он не был синхронизирован с выстрелом. Изменение recoil + TPS по примеру другой игры не подтверждено как работающий вариант в Oxide.

В 0.2.15 тестер подтвердил работу внутреннего модуля, после чего сообщил о бане. Причина по журналам не установлена. Отсутствие `.so` в 0.2.16 не является антибаном.

## Обновление

1. Останови external, полностью закрой игру и старый лоадер. Ранее загруженный модуль остаётся до завершения процесса Oxide.
2. Замени EXE на 0.2.16 и нажми «Скачать файлы». Дождись runtime `oxide-11924-v0.2.16`. Обновление runtime не заменяет сам EXE.
3. Запусти игру и external. Режим Aim — **Camera**. Если CFG требует старый physics line of sight, меню покажет причину блокировки и кнопку очистки этого требования.
4. Для проверки приблизительной видимости включи ESP → Render visibility и сравни цвет цели на открытом месте и за стеной. Сигнал может оказаться непригодным для wallcheck в данной сцене.

## Проверка и ограничения

17/17 локальных CTest, сверка native getter с `libunity.so` 11924 x86_64, проверка menu smoke при 100%/150%, проверка ELF и отсутствия загрузчика internal в payload. В PC-пакете нет `liboxide-runtime.so` и `oxide-injector`.

**0.2.16 не проверена на устройстве.** Эти проверки не подтверждают точность окклюзии, игровые попадания или отсутствие банов.

AutoFarm движется прямо без поиска пути вокруг стен. Auto Melee использует обычную атаку. Silent Farm/Melee без анимаций, свободная камера, автостройка и skip animations не реализованы. Клиентская скорость Reload не гарантирует мгновенную перезарядку на сервере.

Репозиторий содержит описание и бинарники. Исходники соответствующей сборки находятся в отдельном архиве у владельца проекта.
