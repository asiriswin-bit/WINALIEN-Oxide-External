# WIN ALIEN — Oxide External

Лоадер для ПК и Android external под Oxide 1.13.11924 x86_64 в MSI App Player/BlueStacks.

**[Скачать OxideLoader.exe 0.2.8](https://github.com/asiriswin-bit/WINALIEN-Oxide-External/releases/download/oxide-11924-v0.2.8/OxideLoader.exe)** · [Релиз](https://github.com/asiriswin-bit/WINALIEN-Oxide-External/releases/tag/oxide-11924-v0.2.8)

![Игровое меню 0.2.8 — тестовый рендер](menu.png)

Настройки расположения: имя, HP, полоса здоровья, предмет в руках и экипировка могут находиться сверху, снизу, слева или справа. Дистанцию можно оставить с именем или вывести отдельно. Полоса HP сверху/снизу горизонтальная, по бокам вертикальная. Элементы на одной стороне размещаются с отступами.

В шестерёнках доступны размеры текста имени, HP, оружия, отдельной дистанции и категорий World; размер иконок оружия/экипировки; режим предмета в руках «иконка / название / оба». Для World выбираются сторона подписи относительно иконки и отступ. `Player Core → Element spacing` меняет общий отступ аннотаций игрока.

`Skeleton → Head outline` включает контур головы, `Head size` меняет его масштаб. Голова определяется по HitBox.m_HitArea (Head), центр и размер берутся из хитбокса. Если подтверждённого хитбокса головы нет, контур пропускается.

## Что изменилось в 0.2.8

Камера читается на каждом кадре отрисовки. Убраны пауза 100 мс после сбора сцены и ежесекундный сброс кешей. Целевой интервал сбора объектов — 33 мс; фактический FPS зависит от эмулятора и числа объектов.

- World: иконка, название либо оба; дистанция, цвет и размер иконки по категориям.
- Приоритет ближайших объектов, ограничение числа подписей, скрытие перекрытия и затухание у границы дальности.
- Предмет в руках, иконки надетой экипировки, полоса HP.
- Skeleton по доступным костям хитбоксов с дистанцией, цветом и толщиной.
- 228 оригинальных иконок из ассетов 11924. Для 31 из 259 описаний предметов локальная иконка не найдена: используется текст или символ категории.

## Обновление и запуск

1. Останови старый external кнопкой старого лоадера и закрой его.
2. Замени **OxideLoader.exe** версией 0.2.8. Кнопка «Скачать файлы» обновляет runtime и ADB, но не сам EXE.
3. Запусти эмулятор с ADB и Oxide 11924 x86_64, укажи ADB-порт. Бинарнику нужен UID 0 внутри эмулятора; для BlueStacks/MSI лоадер использует встроенный `/system/xbin/bstk/su`.
4. Нажми «Скачать файлы», дождись `oxide-11924-v0.2.8`, затем «Старт external» и «Открыть Oxide».
5. Крестик/Escape скрывают меню. Watermark справа сверху открывает его; Insert работает при запущенном лоадере, F6 переключает ESP.
6. World → шестерёнка категории: дистанция, цвет и режим иконок. World → World Labels → **Compact distances** применяет меньшие дистанции к старому конфигу.
7. В Player включи **Skeleton** и **Equipment**; дальность и оформление — в шестерёнках. Held Item включён по умолчанию.
8. Config сохраняет `/data/local/tmp/oxide-settings.cfg`; есть автосохранение. Останавливай external кнопкой лоадера: закрытие EXE не завершает Android-бинарник.

Комплект использует **протокол 3**: обновить нужно EXE и бинарник. Старые настройки не сбрасываются. Ключ активации не нужен.

## Архитектура и проверка

Игровое меню и ESP рисует Android executable внутри эмулятора через SurfaceControl + EGL/OpenGL ES 3. Windows ImGui/DX11 используется лоадером для загрузки и запуска через ADB. Бинарник читает память игры, не вызывая её методы и не записывая её память.

Меню перенесено из предоставленного WINALIENPRO1protection/Overlay: шрифты Poppins, значки, логотип, watermark, анимации, переносимая панель вкладок, темы и карточки. Доступны прежние рамки, имена, числовое HP, линии, стрелки, фильтры и радар.

Собраны Windows, x86_64 и arm64-v8a. Все 12 наборов CTest проходят, включая ввод и скрытие меню, чтение сцены, смену камеры, оружие/экипировку, кости, режимы World и обновления. Скриншоты выше — тестовый рендер, не снимки игры. Пользователь подтвердил базовый ESP 0.2.7; новые визуалы и прирост плавности 0.2.8 на устройстве ещё не проверены: ADB-устройство при сборке отсутствовало.

**Visible Check с проверкой стен не реализован.** Скелет может быть неполным: рисуются доступные кости хитбоксов, некорректные данные пропускаются. Полоса HP использует максимум 100, если точный максимум отсутствует. Aim, Silent, AutoFarm, Chams и Skins не реализованы. Обход античита не заявляется.

Обёртка native-поверхности рассчитана на Android 9–15; совместимость конкретной прошивки проверяется запуском. При сбое сохрани журнал кнопкой лоадера.
