## Обновление

1. Останови external старым лоадером и закрой его.
2. Замени **OxideLoader.exe**. Кнопка «Скачать файлы» не обновляет сам EXE.
3. Нажми «Скачать файлы», дождись `oxide-11924-v0.2.9`, затем «Старт external».
4. В Player включи Skeleton; в шестерёнке выбери дальность (по умолчанию 120 м).
5. Для деревьев включи Trees; для печек/ящиков Deployables, транспорта Vehicles, бочек/знаков Scrap.

Протокол **4**: EXE и бинарник обновляются вместе. Старые настройки сохраняются. World поддерживает текст/иконки/оба, дистанцию, цвет, размер, разрежение и лимит объектов. В Config именованные пресеты хранятся отдельно от автоматического сохранения текущих настроек. Экспорт: `/data/local/tmp/configs/exports/`; импорт: `.cfg` из `/data/local/tmp/configs/imports/`. Облачные share-коды не подключены.

Крестик/Escape скрывают меню; watermark и Insert открывают его. F6 переключает ESP. Меню и ESP работают внутри эмулятора через SurfaceControl + EGL/OpenGL ES 3; Windows ImGui/DX11 используется лоадером. Для MSI используется встроенный `/system/xbin/bstk/su`; активационный ключ не нужен.

## Проверка

Собраны Windows, x86_64 и arm64-v8a. Все 13 наборов CTest прошли; проверены чтение сцены и модели, обновление ресурсов, конфиги, загрузчик и ввод. Рендер и нажатия меню проверены при 100% и 150%. Скриншоты выше синтетические. **Запуск 0.2.9 в игре ещё не проверен — подключённых ADB-устройств при сборке не было.** Журнал visual_sample показывает категории и причины отсутствия костей.

Visible Check через стены, Aim/Silent, AutoFire, Auto Kill, AutoFarm, No Sway и свободная камера пока не реализованы. Параметры оружия проверены только на синтетической памяти: изменение полей подтверждается чтением, эффект на сервере ещё не проверен. При выключении/штатной остановке оригиналы восстанавливаются, если объект существует и игра не заменила значение. Скелет ограничен прочитанными костями; радиус головы по Transform приблизительный. Полоса HP использует 100 при неизвестном максимуме. Обход античита не заявляется.
