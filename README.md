# WIN ALIEN — Oxide external

Сборка **0.2.18**, профиль **Oxide 1.13.11924 x86_64** для MSI App Player / BlueStacks.

Исправлены обработка универсального инструмента AutoFarm, восстановление камеры после смены матрицы игрой и применение Viewmodel FOV. Добавлены отдельный World FOV, режим Silent camera для добычи и Auto Melee, проверка состава команды по ID и русский язык меню. Радар показывает только противников и NPC. [Изменения и инструкция](https://github.com/asiriswin-bit/WINALIEN-Oxide-External/releases/tag/oxide-11924-v0.2.18).

Silent для стрельбы из 0.2.17 подтверждён пользователем в игре. В 0.2.18 сохранён тот же механизм наведения; изменено восстановление автоматической камеры при конфликте матриц. Новые режимы добычи, Auto Melee и исправления FOV ещё требуют проверки на эмуляторе. Внутренняя `.so` не загружается.

Распакуй **OxideExternal-11924-PC.zip в новую папку**, останови прежний external и перезапусти игру. Запусти новый `OxideLoader.exe`. Для онлайн-версии после замены EXE нажми «Скачать файлы» и проверь версию runtime 0.2.18.

Русский язык: **Settings → последняя карточка Language → Русский**. Для новых стандартных цветов и расположения ESP нажми **ESP → Clean ESP preset / Сбросить стиль ESP**. Сохранённые пользовательские конфиги автоматически не перезаписываются.

Обмундирование по умолчанию сверху над ником, оружие снизу; для каждого выбирается сторона. Скелет белый, контур головы выключен. Видимость определяется по отрисовке модели и одежды; это приблизительный сигнал, не физическая проверка препятствия. Silent camera у ближнего боя сохраняет видимый ракурс, но штатная анимация удара остаётся. AutoFarm идёт прямо к ресурсу без поиска пути и пропускает застрявшие цели.

Исходники — `OxideExternal-11924-source.zip`. Сборка: `powershell -File build.ps1` с Visual Studio C++ Desktop, CMake и Android NDK r27c. `-SkipPayload` пропускает Android-сборку, `-SkipTests` пропускает CTest. ARM64-бинарник собирается для совместимости пакета; игровые функции этого релиза рассчитаны на x86_64.
